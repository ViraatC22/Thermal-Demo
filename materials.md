# Materials Identification

## Overview
This demonstration is a virtual simulation built as a Python web application using the Streamlit framework. It models the thermal interaction between two distinct bodies to illustrate the First and Second Laws of Thermodynamics.

## Software Tools & Libraries

| Item | Description | Purpose | Cost/Accessibility |
|------|-------------|---------|-------------------|
| **Python 3.8+** | Programming Language | The core logic and calculation engine for the simulation. | Free, Open Source |
| **Streamlit** | Python Library | Used to create the interactive web interface, allowing users to manipulate variables (mass, temperature, specific heat) and view results in real-time. | Free, Open Source |
| **Matplotlib** | Python Library | Renders high-quality vector graphics for the physical models (Piston cylinder, Vector Flame, Thermal Blocks). | Free, Open Source |
| **NumPy** | Python Library | Handles numerical calculations for heat transfer, energy balance, and entropy changes. | Free, Open Source |
| **Pandas** | Python Library | Organizes simulation time-series data for analysis and plotting. | Free, Open Source |
| **Plotly** | Python Library | Generates interactive charts (Temperature vs. Time, Entropy vs. Time) to visualize the physical laws. | Free, Open Source |
| **Code Editor** | Software (e.g., VS Code) | For writing and editing the source code (`app.py`). | Free |

## Hardware Requirements

*   **Computer**: A standard laptop or desktop computer capable of running Python.
*   **Browser**: A modern web browser (Chrome, Firefox, Safari) to view the Streamlit app.

## File Structure

*   `app.py`: The main application script containing UI, logic, and visualization code.
*   `requirements.txt`: List of dependencies (streamlit, numpy, pandas, matplotlib, plotly).
*   `materials.md`: List of tools and libraries (this file).
*   `procedure.md`: Step-by-step instructions for running the experiments.
*   `explanation.md`: Theoretical background and mathematical models.
